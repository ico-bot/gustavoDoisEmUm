# Gustavo2em1

Site comercial responsivo e orientado à conversão para a marca Gustavo2em1, com foco em emagrecimento personalizado, catálogo de produtos e conversão via WhatsApp.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- React Helmet Async
- Lucide React

## Como executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Observações

- O conteúdo foi estruturado para ser facilmente adaptado com dados reais do cliente.
- O formulário de contato está preparado para integração futura com um serviço de envio.
- O catálogo usa dados locais e pode evoluir para integração com backend ou API.
